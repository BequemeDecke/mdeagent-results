# mdeagent-results

This repository contains all the data collected during the development of the MDEAgent.

## Framework

- `thesis/Framework Recherche/*`: These files were created while selecting an AI agent framework.

## Aufgaben

- `thesis/Aufgaben.csv`: This file contains information about the tasks the MDEAgent must accomplish.

## Konzept

- `thesis/Komponenten/*`: These files were used to gather information about typical patterns for optimizing AI agents.
- `thesis/Evaluatoren.csv`: This file includes the necessary evaluation implementations to effectively monitor agent performance.

## Evaluation

- `models.csv`: This is a fetched and filtered file containing the models used from the FAU Server for the thesis evaluation.
- `traces/*`: These files are exported CSV files from LangFuse generated during the MDEAgent benchmark.
- `thesis/Benchmark.csv`: This file contains aggregated data used to display the overview table of the benchmark in the thesis.
